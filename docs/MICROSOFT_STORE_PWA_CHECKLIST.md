- API/auth/payment/video requests are intentionally excluded from the service-worker cache.

## Microsoft Store requirements

Microsoft's current PWA publishing guidance requires the website to be served over HTTPS, provide a web app manifest and service worker, and pass Store certification. PWABuilder is the recommended packaging path for a web-first application.

## Packaging flow

1. Deploy the latest `main` branch to `https://apnaacademy.me/`.
2. Open PWABuilder and enter the production URL.
3. Review the PWA Report Card and resolve any production-only warnings.
4. In Partner Center, reserve the ApnaAcademy name and create the Store submission.
5. Copy the generated Package ID, Publisher ID and Publisher display name into PWABuilder.
6. Generate the Windows Store package.
7. Complete Store properties, listing assets, privacy/support information and declarations.
8. Upload the generated package and submit it for certification.

## Final production checks

Before packaging, verify in Microsoft Edge:

- Install prompt/install button appears.
- App opens in standalone mode.
- Refreshing deep links works.
- Login/logout works.
- Course browsing works.
- Course video playback works.
- Payment flow is not intercepted by the service worker.
- API requests continue to use the network.
- Offline navigation shows the offline fallback when appropriate.
- No mixed HTTP content is loaded.

> This checklist records repository readiness. Partner Center account creation, name reservation, package generation and Store submission must be completed using the publisher's Microsoft account.
