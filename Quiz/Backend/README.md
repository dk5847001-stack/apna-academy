# Apna Academy Quiz Backend

This directory contains the independent backend for Apna Academy Quiz.

## Phase 1

The backend is intentionally kept minimal at this stage. No existing ApnaAcademy backend code is imported or reused.

Implementation will be added in later phases under this directory only.

Planned responsibilities:

- REST API
- participant management
- quiz/question management
- attempt lifecycle
- server-side scoring
- results
- leaderboard
- admin authorization
- security and validation

Planned API prefix:

`/api/v1/*`

Production secrets and database credentials must remain in environment variables and must never be committed.
