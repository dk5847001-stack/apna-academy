💎 PHASE 5 — Unlock All + Pricing + Razorpay

Tumhari exact requirement:

DSA App
   ↓
Unlock All DSA Questions
   ↓
ApnaAcademy Pricing Page
   ↓
Select DSA Plan
   ↓
Razorpay
   ↓
Payment Successful
   ↓
Backend verifies payment
   ↓
Subscription / Entitlement activated
   ↓
Redirect back to DSA App
   ↓
All questions unlocked 🔓
Critical point

Payment successful hone ke baad sirf frontend mein isPremium=true nahi karna hai.

Backend:

Payment
   ↓
Razorpay verification
   ↓
Subscription
   ↓
DSA entitlement
   ↓
DSA API

Then DSA app asks:

GET /api/v1/dsa/access

Response:

{
  "dsaAccess": true,
  "plan": "premium",
  "expiresAt": "..."
}

Then:

20% → 100% unlocked

This is important for security.
